# Плейлист в текст

Мини-приложение: берёт файл со списком треков, находит текст каждого в Интернете
и сохраняет результат в TXT и CSV-отчёт.

## Установка

```bash
pip install -r requirements.txt
```

## Использование

Входной файл — по одному треку в строке, в формате `Artist - Title`.
Строки с `#` в начале игнорируются:

```
Dire Straits - Sultans of Swing
Земфира - Искала
```

```bash
python fetch.py tracks.txt -o out.txt
```

На выходе получаются два файла:

- `out.txt` — найденные тексты, каждый с указанием источника и ссылки
- `out.csv` — отчёт: `line, artist, title, status, source, url, synced, chars, error`,
  где `status` — `found`, `not_found` или `parse_error`

### Ключи

| Ключ | Назначение | По умолчанию |
| --- | --- | --- |
| `-o, --output` | файл с текстами | `out.txt` |
| `--csv` | путь к CSV-отчёту | имя выходного файла с `.csv` |
| `--sources` | источники через запятую, по порядку | `lyrics.ovh,lrclib.net` |
| `--timeout` | таймаут запроса, с | `10` |
| `--delay` | пауза между запросами, с | `0.3` |
| `-v, --verbose` | показывать ошибки источников | выкл. |

Код возврата: `0` — все тексты найдены, `1` — есть ненайденные, `2` — ошибка запуска.

## Источники текстов

| Источник | Что даёт |
| --- | --- |
| [lyrics.ovh](https://lyrics.ovh) | открытый API без ключей, хорошее покрытие англоязычных треков |
| [lrclib.net](https://lrclib.net) | открытый API, заметно лучше покрывает русские треки, у части записей есть синхронизированный текст с таймкодами (отмечается в отчёте как `synced=yes`) |

Источники опрашиваются по очереди, побеждает первый, который ответил.
Порядок можно изменить: `--sources lrclib.net,lyrics.ovh`.

Запросы выполняются с `User-Agent`, повторяются при `5xx` с нарастающей паузой,
между обращениями выдерживается интервал, чтобы не нагружать открытые API.

## Ограничения

Тексты берутся из открытых источников и могут быть неполными либо содержать
опечатки. Для личного использования проблемы нет, но публичное распространение
полного текста песни может нарушать авторские права правообладателей.
